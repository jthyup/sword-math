# 연산 대장간 (sword-math)

초등 3학년 수학 문제를 풀어 강화권을 모으고, 망치질로 검을 강화하는 웹 게임입니다.

## 주요 기능

- **문제:** 3학년 1·2학기 12개 단원 + 기초 다지기용 1·2학년 21개 단원(수 세기·시계·자·표 그림 문제 포함). 학생이 여러 단원을 골라 섞어 풀 수 있어요.
- **출제 범위:** 반 공통 범위(기본은 3학년만)와, 학생별 범위(선생님이 학생마다 따로 지정). 학생별 범위가 있으면 그것이 먼저 적용돼요.
- **강화:** 5강마다 다음 단계 검으로 변신해요(20단계, 그 뒤로 ★ 단계가 끝없이 이어져요). +30부터는 날개 효과가 붙어요.
- **보관과 합치기:** 파괴가 걱정되면 검을 보관하고 새로 시작해요. 같은 강화 단계 두 자루를 합치면 다음 단계로 100% 강화돼요.
- **선생님 관리:** 출제 범위 설정, 학생 가입 허용, 학생별 기록(정답률, 약한 단원, 현재·최고 무기).
- **랭킹:** 최고 무기, 이번 주(월요일 0시 시작) 맞힌 문제 수. 상위 10명과 내 순위, 랭킹용 별명. 선생님이 켜고 끌 수 있어요.
- **테스트 모드:** 강화권 무제한, 무조건 강화 성공, 도감에서 무기 바로 바꾸기. 기록은 저장되지 않아요.

## 실행

GitHub Pages 주소: https://jthyup.github.io/sword-math/

- **학생:** "처음 왔어요"로 이름과 비밀번호 숫자 4자리를 정해 가입하고, 다음부터 같은 이름과 비밀번호로 들어와요.
- **선생님:** "선생님 로그인 (구글)"로 들어오면 모든 학생 기록, 출제 범위, 가입 허용 설정이 보여요.
- **로그인 없이 체험하기:** 기록이 그 기기에만 저장돼요.

## Firebase 구성

- 프로젝트: `project-eraser-71be8` (Spark 무료 요금제)
- Authentication: 이메일/비밀번호(학생), Google(선생님). 승인된 도메인에 `jthyup.github.io` 추가
- Firestore: `asia-northeast3 (서울)`. 이 게임의 데이터는 `sm_students`(학생 기록), `sm_settings`(설정), `sm_rank`(랭킹판: 별명·최고 강화·주간 문제 수)에만 저장해요.
- 보안 규칙: `firestore.rules` 내용을 Firebase 콘솔 > Firestore Database > 규칙 탭에 붙여 넣고 게시해요. 규칙을 고치면 콘솔에서도 다시 게시해야 해요.

학생 이름은 로그인용 내부 주소(`s…@sword-math.app`, 실제 메일 아님)로 바뀌어 저장돼요. 학생이 비밀번호를 잊으면 선생님이 기록을 지우고, 이름에 번호를 붙여 다시 가입하게 해 주세요.

## 파일 구성

- `index.html`: 게임 전체(화면, 문제 생성, 강화 규칙, 저장)
- `img/wing1~10.webp`: 검 뒤 날개 (+30부터 10단계)
- `img/login-bg.webp`: 로그인 화면 대장간 배경
- 픽셀 검 그림은 `index.html` 안에 들어 있어요.
