# 연산 대장간 (sword-math)

초등 3학년 수학 문제를 풀어 강화권을 모으고, 망치질로 검을 강화하는 웹 게임입니다.

## 주요 기능

- **문제:** 2022 개정 교육과정 3학년 1·2학기 12개 단원. 학생이 여러 단원을 골라 섞어 풀 수 있어요.
- **강화:** 5강마다 다음 단계 검으로 변신해요(20단계, 그 뒤로 ★ 단계가 끝없이 이어져요). +30부터는 날개 효과가 붙어요.
- **보관과 합치기:** 파괴가 걱정되면 검을 보관하고 새로 시작해요. 같은 강화 단계 두 자루를 합치면 다음 단계로 100% 강화돼요.
- **선생님 관리:** 출제 범위 설정, 학생 가입 허용, 학생별 기록(정답률, 약한 단원, 현재·최고 무기).
- **테스트 모드:** 강화권 무제한, 무조건 강화 성공, 도감에서 무기 바로 바꾸기. 기록은 저장되지 않아요.

## 실행

`index.html`을 브라우저로 열면 체험 모드(기록은 그 기기에만 저장)로 동작해요.
GitHub Pages 주소: https://jthyup.github.io/sword-math/

> 학생 가입·선생님 관리처럼 여러 기기의 기록을 모으는 기능은 Firebase 연결 후 동작합니다(작업 예정).

## 파일 구성

- `index.html`: 게임 전체(화면, 문제 생성, 강화 규칙, 저장)
- `img/w00.webp` ~ `img/w19.webp`: 일러스트 검 그림(20단계)
- `img/fx*.png`: 날개 효과 애니메이션(가로 8장)
- 픽셀 검 그림은 `index.html` 안에 들어 있어요.
